# Reviggo — Protocolo Corpo Revigorado

**Subtítulo oficial:** 300 receitas para você que não aguenta mais conviver com dores e quer voltar a ter energia e liberdade.

Este é o pacote final para implementação do aplicativo **Reviggo**. O programa interno de 21 dias se chama **Protocolo Corpo Revigorado**.

Arquivos principais para implementação:

- `receitas_300.json` — fonte de verdade das 300 receitas revisadas
- `plano_21_dias.json` — plano revisado
- `prompt_codex_app_FINAL.md` — prompt recomendado para implementação
- `AUDITORIA_FINAL.md` — resumo da revisão
- `biblioteca_300_receitas.md` — versão humana da biblioteca
- `indice_por_objetivo.md` — índice por filtro
- `receitas_300.csv` — apoio para conferência
